# 🎬 Graph-Based Recommendation System Using Personalized PageRank

##  Project Description
This project explores the application of Graph Data Science in recommendation systems using the MovieLens dataset.

The system models users and movies as a bipartite graph and applies graph algorithms to generate personalized movie recommendations.

In addition, the project compares graph-based recommendation methods with traditional non-graph recommendation approaches.

---

##  Objectives
- Apply Graph Data Science concepts in a real-world dataset.
- Build a graph-based recommendation system.
- Compare graph and non-graph recommendation techniques.
- Evaluate recommendation quality using ranking metrics.

---

##  Implemented Models

### Graph-Based Models
- Personalized PageRank (PPR)
- LightGCN

### Non-Graph Models
- User-Based KNN
- SVD
- Neural Collaborative Filtering (NCF)

---

##  Evaluation Metrics
The models were evaluated using:
- Precision@10
- Recall@10
- NDCG@10

---

##  Dataset
MovieLens Dataset

---

##  Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- NetworkX
- PyTorch
- Scikit-learn
- Graph Data Science

---

##  Results Summary
- User-Based KNN achieved the highest recommendation performance.
- LightGCN produced competitive ranking results.
- Personalized PageRank achieved lower performance due to dataset density and interaction structure.
